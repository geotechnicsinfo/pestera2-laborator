Rezistența la forfecare: φ și c caracteristice

Metodă

n ≥ 3 → Xm = ΣXi / n · sx = √[Σ(Xi − Xm)² / (n − 1)] · Vx = sx / Xm
kn = 1 / (−3,1623769 + 2,9383998 · n^0,2232684) pentru 3 ≤ n ≤ 30; kn = 0,31 pentru n > 30
Xk,inf/sup = Xm · (1 ∓ kn · Vx) · Xk,loc inf/sup = Xm · (1 ∓ 2 · Vx) · n < 3 → valori informative
φ: statistica se face pe tgφ, apoi φk = arctg(tgφk). Valoarea inferioară sau superioară se alege după efectul defavorabil în calculul respectiv.
